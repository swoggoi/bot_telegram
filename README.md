# Telegram Video Bot with Referral System

Telegram-бот для продажи цифровых видео через Telegram Stars с реферальной системой скидок.

## Установка и запуск

### 1. Клонируйте репозиторий

```bash
git clone https://github.com/your-username/your-repo-name.git
cd your-repo-name
```

### 2. Создайте виртуальное окружение

```bash
python -m venv venv
```

**Windows:**
```bash
venv\Scripts\activate
```

**Linux/Mac:**
```bash
source venv/bin/activate
```

### 3. Установите зависимости

```bash
pip install -r requirements.txt
```

### 4. Создайте файл .env

```bash
cp .env.example .env
```

Отредактируйте файл `.env` и вставьте реальный токен бота:

```
BOT_TOKEN=ваш_реальный_токен
ADMIN_ID=7352621949
```

### 5. Запустите бота

```bash
python bot.py
```

Бот запустится через long polling и начнёт обрабатывать сообщения.

## Деплой на сервер (VPS)

### Через systemd (Linux)

1. Загрузите файлы на сервер:

```bash
scp -r ./* user@your-server:/opt/video-bot/
```

2. Подключитесь к серверу и установите зависимости:

```bash
ssh user@your-server
cd /opt/video-bot
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

3. Создайте файл `.env` с реальным токеном:

```bash
nano .env
```

4. Создайте systemd-сервис:

```bash
sudo nano /etc/systemd/system/video-bot.service
```

Содержимое:

```ini
[Unit]
Description=Telegram Video Bot
After=network.target

[Service]
Type=simple
User=your-user
WorkingDirectory=/opt/video-bot
ExecStart=/opt/video-bot/venv/bin/python bot.py
Restart=always
RestartSec=10
Environment=PYTHONUNBUFFERED=1

[Install]
WantedBy=multi-user.target
```

5. Запустите сервис:

```bash
sudo systemctl daemon-reload
sudo systemctl enable video-bot
sudo systemctl start video-bot
```

6. Проверьте статус:

```bash
sudo systemctl status video-bot
```

7. Смотрите логи:

```bash
sudo journalctl -u video-bot -f
```

## Инструкция для администратора

### Как открыть админ-панель

Отправьте боту команду `/admin`. Доступ имеет только пользователь с ID `7352621949`.

### Как добавить видео

1. Нажмите «➕ Добавить видео» в админ-панели.
2. Бот запросит **название видео** — введите текст.
3. Бот запросит **описание** — введите текст.
4. Бот запросит **цену в Telegram Stars** — введите целое число (например, `100`).
5. Бот запросит **само видео** — отправьте видео-файл (не документ, а именно видео через кнопку прикрепления → Видео/Фильм).
6. После загрузки бот покажет карточку товара с ID, названием, ценой, описанием и датой.

### Как изменить цену

1. Нажмите «💰 Изменить цену».
2. Введите ID товара (виден в списке товаров).
3. Введите новую цену в Stars.

### Как удалить товар

1. Нажмите «🗑 Удалить товар».
2. Введите ID товара.
3. Подтвердите удаление.
4. Товар будет деактивирован (история покупок сохраняется).

### Как посмотреть статистику

Нажмите «📊 Статистика» в админ-панели. Будет показано:
- Количество пользователей
- Количество активных товаров
- Количество оплаченных заказов
- Общая выручка
- Количество активных рефералов

### Как посмотреть список товаров

Нажмите «📋 Список товаров» — отобразятся все активные товары с ID, названием, ценой и датой добавления.

## Важные замечания

### Бот должен быть запущен постоянно

Бот работает через **long polling** — он постоянно опрачивает серверы Telegram на наличие новых обновлений. Если бот остановлен, он не будет обрабатывать сообщения, платежи и выдавать видео. Убедитесь, что бот запущен на надёжном сервере с постоянным доступом в интернет.

### Пользователь должен нажать /start

Чтобы бот мог отправлять пользователю сообщения (уведомления о покупке, видео и т.д.), пользователь должен **открыть чат с ботом и нажать /start**. Без этого Telegram не разрешает боту инициировать переписку.

### Реферальная система

- Пользователь получает персональную ссылку через `/referrals` или меню.
- Скидка рассчитывается автоматически при создании платежа.
- Внутренний баланс реферальных комиссий — это **не автоматический перевод Stars**. Выплаты производятся вручную администратором.

### Telegram Stars

- Бот использует встроенные платежи Telegram Stars (валюта `XTR`).
- `provider_token` оставлен пустым — это требование Telegram для Stars.
- Бот поддерживает возврат средств через `refundStarPayment`.

### Безопасность

- Токен бота хранится в переменной окружения, НЕ в коде.
- Цену товара бот берёт из базы данных, не из callback_data.
- Проверяется владелец заказа перед оплатой.
- Двойная защита от повторной обработки платежей.
